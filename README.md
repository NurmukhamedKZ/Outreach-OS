## Команды

Python-конвейер живёт в `backend/`, консоль оператора — во `frontend/`.
Команды ниже запускаются из `backend/`.

```bash
uv run collect.py                      # ходит в сеть, наполняет raw/
uv run --env-file .env classify.py     # профиль и why_now от OpenAI, в raw/*.llm.json
uv run build.py                        # raw/ -> leads.db, ни одного сетевого запроса
uv run report.py                       # leads.db -> leads.csv, 30 лидов
uv run check.py                        # восемь разделов ассертов на живых данных
```

`build.py` — граница системы: слева от неё то, что нельзя восстановить, справа то,
что пересобирается бесплатно. Поэтому она не импортирует ни `fetch`, ни `scrapling`,
и `check.py` это проверяет.

## Веб-интерфейс

Два процесса. Бэкенд читает `leads.db`, фронтенд проксирует `/api/*` на него, так что
браузеру нужен только порт 3000.

```bash
cd backend  && uv run uvicorn api:app --port 8787 --reload   # FastAPI
cd frontend && npm run dev                                   # Next.js -> http://localhost:3000
```

Что делает оператор: смотрит лид, читает `why_now` с цитатой с сайта компании,
копирует канал, пишет руками. Статус переписки в систему не возвращается — это
работа человека в его таблице.

## `raw/` — слой сырья

Скачанные страницы: `<sha1(url)>.html.gz` и сайдкар `<sha1(url)>.json`
(`url`, `final_url`, `status`, `fetched_at`). Ответы модели — `<sha256>.llm.json`.

**Папка невосстановима.** Вакансия закрывается, страница удаляется — перекачать
собранное нельзя. В git она не хранится (на целевом объёме это гигабайты), поэтому
**бэкапится отдельно**, вне репозитория.

Не удалять. Не чистить как кэш. `final_url` из сайдкара — единственный способ
поймать молчаливую подмену страницы источником.

## `suppression.csv` — юридический контур

Кому больше не писать (закон РК №94-V, PRD F21). Файл, а не таблица: схема
пересобирается через `DROP`, и запись, сделанная напрямую в базу, исчезла бы на
ближайшей сборке. Список никогда не очищается.

Пополняется из веб-интерфейса или руками; `build.py` заливает его в `leads.db`,
`report.py` и API проверяют **до** выдачи, а не после.
