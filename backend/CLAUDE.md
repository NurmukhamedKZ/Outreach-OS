# backend/CLAUDE.md

Правила для кода FastAPI-бэкенда. Дополняют корневой `CLAUDE.md` (принципы кода, безопасность, работа с тикетами); при противоречии побеждает корневой. Основа — гайд «FastAPI Best Practices for AI Agents» в том виде, в каком он адаптирован в проекте GoCastMVP; что не зависит от выбора базы — перенесено, остальное ждёт редизайна.

**Правила описывают новый код.** Существующие `collector/`, `writer/`, `sender/` написаны до них (функции, швы `use()`, папки `routes/`/`services/`/`db/`) и заменяются модулями предметной области по мере переписывания (#9–#13, затем #7), а не отдельной кампанией.

**Модули** лежат прямо в `backend/`, имена — из `GLOSSARY.md`: `companies`, `research`, `refusals`, позже `conversations`, `delivery`, `overview`. Общее ядро без бизнес-логики — `backend/core/` (не `platform`: это модуль стандартной библиотеки). Зависимости идут в одну сторону: `companies` → `research` → `conversations` → `delivery`; `refusals` зовут все. Состав и причины — #4.

**База — одна SQLite без прогонов** (ADR 0002). Разделы «База данных», «Async», «Миграции» дописывает #9: способ миграций и синхронный или асинхронный доступ решаются на его грилинге.

**Настройки оператора — в базе** (ADR 0003): модуль сам описывает свои настройки и умолчания и отдаёт их своим API, `core` только хранит. Отдельного модуля настроек нет.

## Версии

Python 3.13 · FastAPI ≥ 0.141 · Pydantic ≥ 2 · pydantic-settings ≥ 2.15 · LangChain ≥ 1.3 · httpx ≥ 0.28 · pytest ≥ 8.

## Структура модуля

Код раскладывается по модулям предметной области, а не по типам файлов:

| Файл | Что внутри |
|---|---|
| `api.py` | роутер FastAPI — только HTTP |
| `dependencies.py` | зависимости роутов: загрузка и проверка объекта из пути, сборка сервиса |
| `service.py` | класс сервиса модуля — бизнес-операции и транзакция |
| `repository.py` | класс репозитория — SQL к своим таблицам |
| `schemas.py` | Pydantic-схемы запросов и ответов |
| `exceptions.py` | доменные исключения модуля (своих нет — файла нет) |
| `domain.py` | чистые функции без ввода-вывода, только где домен богатый (гейты, скоринг, разбор страниц) |
| `public.py` | фасад для других модулей; появляется вместе с первым внешним вызовом, не заранее |

**Не заводим** `utils.py`, `constants.py`, `helpers.py` «на всякий случай»: константа живёт рядом с тем, что её использует, или в `StrEnum` в `schemas.py`.

## Импорты между модулями

Другие модули импортируют **только `public.py`**, никогда `service`, `repository` или `schemas` чужого модуля. Импорт — явным именем модуля:

```python
from delivery import public as delivery

delivery.enqueue(db, thread_id, now)
```

Функции `public.py` тонкие и сами собирают сервис: чужой модуль не зависит от устройства чужих классов. `from x import *` и глубокие пути в чужие модули запрещены. Граф сторожат `*/tests/test_import_graph.py`; import-linter — #5.

## Pydantic

- Встроенные валидаторы вместо ручных: `Field(min_length=, max_length=, ge=, pattern=)`, `AnyUrl`, `StrEnum`. Ограничения совпадают с `CHECK` в схеме базы.
- Не противоречь себе: `Field(ge=1, default=None)` — ошибка. Либо обязательное `Field(ge=1)`, либо `int | None = Field(default=None, ge=1)`.
- Нормализация входа (Postel's Law) — валидатором схемы: обрезка пробелов, телефон в каноническую форму, домен в нижний регистр, ник Instagram без `@`.
- Сериализация — `@field_serializer` / `Annotated[T, PlainSerializer(...)]`, не `json_encoders`. Время — ISO 8601 с таймзоной.
- Лишние поля во входе игнорируются (поведение по умолчанию), `extra="forbid"` не ставим.
- **Общая база схем** — один `class Schema(BaseModel)` с общим `model_config` и типом `Timestamp` (только с таймзоной). Все схемы запросов и ответов наследуют её — единственное наследование помимо исключений.
- **Ошибки — кодами, а не фразами.** Валидатор бросает `ValueError("errors.phoneInvalid")`, доменное исключение несёт `code`; наружу уходит `{"code": "errors.numberExists", "detail": "…"}`. Фронт ветвится по `code`, текст — для человека.

## Настройки

- `config.py` — единственное место чтения переменных окружения (`Settings(BaseSettings)`, читает `backend/.env`). `os.environ` в коде модулей не используется.
- То, что меняет оператор (сегменты, размер партии, модель, веса, окна, лимиты), — настройки модуля в базе, правятся на странице «Настройки». Новых `config.toml` не заводим.
- То, что защищает от капчи и бана (темп сети по хостам, число потоков, ретраи, адреса источников), — константы в коде модуля.
- Никаких значений по умолчанию для секретов.

## Зависимости

- Только `Annotated`-форма; алиасы объявляются рядом с зависимостью:

```python
Db = Annotated[sqlite3.Connection, Depends(get_db)]
ThreadDep = Annotated[Thread, Depends(valid_thread_id)]
DeliveryServiceDep = Annotated[DeliveryService, Depends(get_delivery_service)]
```

- **Зависимость проверяет, а не просто внедряет:** `valid_thread_id` загружает тред или бросает `NotFound` (404). Можно ли действие — решает сервис.
- Сервис получает зависимости в конструкторе (соединение, транспорт, модель, конфиг) и никогда не создаёт клиентов сам. Сборка — в `dependencies.py` для запроса и в `main.py` для фоновых задач.
- Время — параметром `now`; читает его одна функция (`clock.now()`) на границе: в роуте или в тике.
- Одинаковое имя параметра пути во всех роутах, где нужна общая зависимость (`thread_id`, `company_id`).

## Комментарии и docstring

- **Язык в новом коде — английский:** комментарии, docstring, сообщения для разработчика. Документация (`*.md`, спеки, ADR), коммиты и тексты для оператора — на русском. Старые русские комментарии специально не переводим: они уходят вместе с переписанным файлом.
- **Формат — PEP 257 + Google style.** Первая строка — резюме: у функции в повелительном наклонении (`Return…`, `Queue…`), у класса — описание. Дальше при необходимости `Raises:`, `Returns:` (когда смысл не виден из типа). `Args:` не пишем — типы в сигнатуре.
- **О чём писать:** зачем и какой контракт — побочные эффекты, что бросает и когда. Реализацию не пересказываем. Имя и сигнатура всё говорят — docstring не нужен; плохое имя лучше переименовать, чем объяснять.
- **Обязательно:** функции `public.py`, методы сервисов, Protocol-границы.
- **Не пишем:** у тестов (контракт — в имени теста) и у роутов — их описание в `summary=` декоратора.
- **Комментарий объясняет «почему»**, а не «что».

## Фоновые задачи

- `BackgroundTasks` — только для коротких необязательных дел после ответа. Задача умирает вместе с процессом и не ретраится — ничего, что нельзя потерять.
- Всё, что нельзя потерять, — строка состояния в таблице модуля и шаг тика, а не задача в памяти: очередь `outbox`, срок касания `threads.next_touch_at`, джобы `state.jobs`.
- Демон не работает молча: исход каждого тика — запись в журнал `activity`.

## Тесты

- **Сначала тест, потом код (TDD).** Каждое поведение начинается с падающего теста, затем минимальный код до зелёного, затем рефакторинг под зелёными тестами.
- HTTP-шов — `httpx.AsyncClient` + `ASGITransport(app=app)` или `TestClient`.
- **Базу не мокаем:** настоящая база во временном файле со схемой, которую создают владельцы таблиц.
- `app.dependency_overrides` и Fake-реализации — только для внешних границ: модель (OpenRouter), транспорт WhatsApp (Node), сетевой сбор (scrapling). Тесты в сеть не ходят.
- Часы подменяем там, где их читают, — одной функцией; `now` дальше идёт параметром.
- Числа в тестах разбора — свойства эталонных страниц из `fixtures/`; расхождение значит, что поехал разбор.

## Логи

- Логгер модуля — `log = logging.getLogger(__name__)`. Никаких `print`, `logging.basicConfig`, своих хендлеров: формат задаёт `logging_setup.py`.
- **В лог — идентификаторы, а не данные.** Телефоны, тексты сообщений, тела запросов и ключи не логируем. `thread_id` сейчас — телефон лида, поэтому новый код в лог его не пишет; чем его заменить, решает #7.
- Уровни: `error` — надо разбираться человеку, `warning` — деградация без ошибки для оператора, `info` — редкие значимые события.
- Необработанное исключение уже попадает в лог — не ловим его, чтобы залогировать. `log.exception` — только когда ошибку обработали и работа продолжается.

## Документация API

Каждый роут объявляет `status_code`, тип ответа, `summary`, `tags` и ошибки в `responses=`. Тип ответа задаём **одним** способом: аннотацией возврата или `response_model`, не обоими.

## Анти-паттерны — проверяй в каждом диффе

| Анти-паттерн | Почему плохо | Как надо |
|---|---|---|
| `requests`, `time.sleep`, синхронный `open()` в `async def` | Блокирует event loop всего процесса | httpx.AsyncClient, `asyncio.sleep`, `asyncio.to_thread` |
| `json_encoders` в `ConfigDict` | Удалён в Pydantic v2 | `@field_serializer` |
| `Field(ge=1, default=None)` | Ограничение противоречит умолчанию | Обязательное или `X \| None` |
| `x: T = Depends(...)` | Устаревшая форма | `Annotated[T, Depends(...)]` |
| `except Exception` вокруг тела роута | Прячет баги, 500 превращается в 200 | Ловить конкретное, бросать доменное исключение |
| Импорт `service`/`repository`/`schemas` чужого модуля | Ломает границы модулей | Только `from x import public` |
| SQL к таблице чужого модуля | Скрытая связность модулей | Функция `public.py` владельца |
| Сеть или вызов модели внутри транзакции | Нарушает атомарность, держит блокировку записи | Сначала коммит, потом вызов; изменения наружу — after-commit |
| «Прочитал статус, потом записал» | Гонка между тиком и кнопкой оператора | `UPDATE … WHERE status = :from`, ноль строк — конфликт |
| Модульный шов `use()` или глобальная переменная с соединением | Скрытый синглтон, тесты зависят от порядка | Зависимость в конструктор или параметром |
| `T \| None` как признак ошибки | Проверка расползается по всем вызывающим | Доменное исключение |
| Мок базы в тесте | Расхождение с настоящей схемой | Временный файл базы |
| `response_model=X` и `return X(...)` одновременно | Двойная валидация | Один способ |
| `utils.py`, `helpers.py`, `BaseService` | Свалка и абстракции без причины | Код рядом с доменом (корневой `CLAUDE.md`) |
| `raise ValueError("Телефон неверный")` в валидаторе | Фронт вынужден ветвиться по тексту | `ValueError("errors.phoneInvalid")` |
| Схема от голого `BaseModel` | Разный формат времени в модулях | Наследовать общую `Schema` |
| `print()`, `logging.basicConfig`, свой хендлер логов | Мимо общего формата | `logging.getLogger(__name__)` |
| Телефон или текст сообщения в логе | Персональные данные в файлах логов | Логировать идентификатор |
| `datetime.now()` в сервисе или домене | Тест зависит от времени запуска, песочница не может сдвинуть часы | `clock.now()` на границе, дальше параметр `now` |
